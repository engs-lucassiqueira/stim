# Stim

Stim é um projeto de interface para uma loja de jogos, inspirado em plataformas de distribuição digital. O site reúne páginas de loja, biblioteca, perfil, comunidade, avaliações, lista de desejos, carrinho e insígnias.

## Acesso ao site

[Abrir a página inicial do site] https://engs-lucassiqueira.github.io/stim/

## Conceitos aplicados

O design usa hierarquia visual para destacar títulos, jogos e preços. Contraste entre o fundo escuro, os textos claros e o verde ajuda na leitura e chama atenção para elementos importantes. A repetição do cabeçalho, das cores e dos estilos nas páginas mantém a consistência. Os elementos relacionados ficam agrupados em cartões e listas, facilitando a localização das informações. O layout também se adapta a telas menores.

## Escolhas de design

As cores escuras e o verde foram escolhidos para criar uma aparência ligada ao universo dos jogos e manter boa distinção entre fundo, texto e destaques. Os cartões organizam os jogos e suas informações em blocos; títulos maiores e preços em destaque ajudam o usuário a entender rapidamente o conteúdo. O menu aparece em todas as páginas para facilitar a navegação. O uso de grades e ajustes para telas menores aplica os conceitos de organização, alinhamento e design responsivo estudados em sala.
